# Practical 8 — Dynamic student manager
1. Run `npm install` in this folder.
2. Copy `.env.example` to `.env`.
3. Start MongoDB and run `npm start`.
4. Create a Vite React app in `frontend`, then place the supplied files under `src/`.
5. Run `npm install` and `npm run dev` in `frontend`.

API endpoints under `/api/students`: GET, POST, PUT `/:id`, DELETE `/:id`.
Search filters the loaded records by name, email, course, and city.
