# Practical 4 — Update and Delete
This practical continues the Q3 student CRUD example. It uses the same `studentDB` database and `/student` base path.
- `POST /student` — create
- `GET /student` — read all
- `PUT /student/:id` — update
- `DELETE /student/:id` — delete
Install dependencies using `npm install`; start MongoDB, then run `npm start`.
Create a Vite React app in `frontend`, install `axios`, and use the supplied `src/App.jsx`.
